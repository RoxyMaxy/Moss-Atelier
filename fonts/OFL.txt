SIL Open Font License (OFL) Documentation for Moss Atelier
============================================================

The following typefaces are utilized in the "Atelier Night" design:

1. Fraunces
   - Designed by Phaedra Charles and Flavia Zimbardi (Undercase Type).
   - Weights: 600–700 (Titles, Gift names).
   - License: SIL Open Font License, Version 1.1.

2. Atkinson Hyperlegible
   - Designed by Braille Institute of America & Applied Design Works.
   - Size/Leading: 16px, line-height 1.6 (Body, controls).
   - License: SIL Open Font License, Version 1.1.

3. Press Start 2P
   - Designed by CodeMan38.
   - Size: 10–12px (Sloth status, pixel counters).
   - License: SIL Open Font License, Version 1.1.

System fallback stacks:
- Fraunces: 'Fraunces', 'Georgia', 'Playfair Display', serif
- Atkinson Hyperlegible: 'Atkinson Hyperlegible', system-ui, -apple-system, sans-serif
- Press Start 2P: 'Press Start 2P', 'Courier New', monospace
